== Description ==

Launch a professional website for your business with the Elayne WordPress block theme — 140+ beautiful, ready-to-insert block patterns (including full-page compositions that assemble a complete page in one paste), 8 one-click style variations, WooCommerce store templates, and a fully-customizable design system with Global Styles. No expensive page builder plugin required.

Every demo below is a live Elayne site — pick the one closest to your business, insert its patterns, replace the words:

* Main theme homepage (Bold style variation): https://demo.imagewize.com/
* Restaurant or cafe (Bistro style variation): https://demo.imagewize.com/kafe/
* Spa and wellness: https://demo.imagewize.com/spa/
* Home services and trades: https://demo.imagewize.com/plumbing/
* Nail salon and beauty: https://demo.imagewize.com/nail-salon/
* Shop with WooCommerce: https://demo.imagewize.com/store/
* Law firm (Elayne Legal child theme): https://demo.imagewize.com/legal/

= Key Features =

* 140+ Professional Patterns - All 100% original, created specifically for Elayne
* Ready-to-Insert Page Patterns - Full-page compositions (Homepage, Agency Homepage, About, Contact, Services, plus Store Homepage, Shop, Cart, and Checkout) that assemble multiple section patterns in a single paste
* 32 Interactive CSS Effects - Pure CSS animations for buttons, cards, images, and text
* WooCommerce Integration - Custom product archive template with responsive 3-2-1 grid
* 8 Style Variations - Complete design systems including Bistro, Food & Beverage, Spa & Wellness, Home Improvement, Nail Salon, and Publicist (Legal Blue deprecated in 4.13.0, see below)
* Flexible Layout System - Multiple page & post layout options (centered, sidebar, wide)
* Business/Corporate Focus - Professional patterns for modern businesses
* Industry-Specific Content - Pattern sets optimized for spa & wellness, legal services, food & beverage, home improvement trades, nail salons, and publishing
* Sophisticated Design - Clean, modern patterns with professional aesthetics
* Conversion Optimization - Built-in patterns designed to convert visitors into customers
* Full Site Editing (FSE) - Complete control over your site design
* Block Extensions - Enhanced navigation and post excerpt functionality
* Fluid Typography - Responsive font scaling with clamp()
* Custom Shadows - Multiple shadow presets for depth

== Installation ==

1. In your WordPress admin panel, go to Appearance > Themes and click the Add New button.
2. Click Upload Theme and Choose File, then select the theme's .zip file. Click Install Now.
3. Click Activate to use your new theme right away.

== Frequently Asked Questions ==

= Does this theme support Full Site Editing? =

Yes! Elayne is built as a modern block theme with full support for WordPress Full Site Editing (FSE).

= Can I customize the colors and fonts? =

Yes, all theme settings including colors, fonts, and spacing can be customized through the WordPress Site Editor using theme.json settings.

= Are the patterns customizable? =

Absolutely! All patterns are built with WordPress blocks and can be fully customized using the block editor.

= What image sizes does the theme use? =

Elayne includes custom image sizes optimized for different layouts:
* elayne-portrait-small (380×570) - 2:3 aspect ratio
* elayne-portrait-medium (380×507) - 3:4 aspect ratio
* elayne-portrait-large (380×475) - 4:5 aspect ratio
* elayne-single-hero (700×400) - 16:9-ish landscape

= Do I need a page builder plugin like Elementor or Divi? =

No. Elayne is built entirely on WordPress core blocks and the native Site Editor. If you ever switch themes, your content stays as standard WordPress blocks — no lock-in, nothing to rebuild.

= Will it work with my existing content? =

Yes. Elayne uses the standard WordPress template hierarchy, so your existing posts, pages, and menus keep working. Insert Elayne patterns where you want a designed section.

= Do I need WooCommerce? =

Only for the shop. Without WooCommerce, the store patterns and templates are hidden and unregistered — you get a normal business theme with no leftover placeholders.

= Is it really free? =

Yes — Elayne is free and GPL-licensed, from the WordPress.org theme directory. Optional companion plugins (the Aludra block library and the Waygate AI builder) are free too.

= What is the difference between Elayne and the child themes? =

Elayne is the full theme for general business and shop sites. A child theme such as Elayne Legal adds one industry's design — its own patterns, style variation, header and footer — on top of Elayne, which stays installed as the parent.

= Will I lose my work when I switch style variations? =

No. A style variation only changes the global design — colors, fonts, buttons. Your pages and content are untouched, and you can switch back at any time in Appearance → Editor → Styles.

* DEPRECATED: The bundled legal patterns (elayne/legal-about-intro, elayne/legal-contact, elayne/legal-services, elayne/legal-stats, elayne/legal-team, elayne/legal-testimonials, elayne/hero-cover-slanted-legal) and the Legal Blue style variation; their descriptions now say so. = 4.12.0 - 11/14/26 =
* ADDED: Colour contract. Patterns, template parts, templates and the shared CSS now use only the palette colours every style variation defines, so any pattern reads correctly under any variation. New palette colours in theme.json and every variation: on-primary (text on a primary background), accent (kickers, eyebrows and accent buttons on the page) and accent-light (highlights on dark bands). The old orange, orange-light, gold and accent-warm colours stay defined, so saved content keeps its colours.
* ADDED: Fallbacks for sites whose saved global styles predate the new colours (--elayne-on-primary, --elayne-accent, --elayne-accent-light), and fixed status colours for form and WooCommerce notices.
* FIXED: Plumbing, Store/WooCommerce, Nail Salon, Food & Beverage and other vertical patterns under other style variations: white text on cream, invisible labels and badges, backgrounds in colours only one variation defined, and gradients that rendered nothing.
* FIXED: Comment titles, dates and links in every post and page template, footer meta, post-loop terms and testimonial roles used a background colour as text and were nearly invisible. They now use main-accent.
* FIXED: Spa variation contrast. Muted text, tinted sections and primary-alt bands now pass WCAG AA. Sites that already saved Spa keep their old palette.
* FIXED: Nail Salon pattern layout (why-us column, hero card, featured testimonial) never loaded; it now applies under every variation.
* FIXED: Block validation errors in about 30 patterns after WordPress core save changes, and WooCommerce patterns that never got the heading font they asked for.
* TECHNICAL: composer check:colors (bin/check-colors.php) checks the colour contract and prints a WCAG contrast report per variation; it runs in CI and can check a child theme.

= 4.11.2 - 11/12/26 =
* Fixed: the GitHub release zip now wraps the theme in its own `elayne/` folder, so uploading it on WordPress 7.1.4 or later no longer installs the theme in a randomly named folder.

= 4.11.1 - 10/25/26 =
* NOTICE: New industry verticals now ship as child themes that require Elayne as the parent, starting with Elayne Legal (https://github.com/imagewize/elayne-legal, not on WordPress.org). Elayne itself is unchanged and keeps working as before; no new vertical pattern sets will be added to this theme.
* NOTICE: The legal patterns and the Legal Blue style variation bundled here stay in place for now, and will be deprecated in a later release once Elayne Legal is established.
* CHANGED: Development tooling bumped, pt-cli to 2.6.0 (image-height-auto rule) and @imwz/wp-pattern-sentinel to 1.2.2. No theme output changes.
* DOCS: README rewritten around the child-theme direction, with corrected requirements (WordPress 7.0) and install options. CLAUDE.md, AGENTS.md and README document the vertical child theme setup and the private elayne-content prototype repo.

= 4.11.0 - 10/15/26 =
* ADDED: Author archive template (templates/author.html, pattern elayne/template-author-archive). Shows the author's avatar, name and profile biography above the post grid; no empty paragraph when the biography is blank.
* ADDED: elayne/author Block Bindings source (inc/author-bindings.php) exposing the archive author's name, biography and avatar URL to core blocks at render time.
* ADDED: elayne/post-author-box pattern, a card at the end of single posts with avatar, author name linked to the author archive and biography. Used by all four single-post layouts.
* TECHNICAL: The single-post byline author name now links to the author archive.

= 4.10.0 - 09/05/26 =
* CHANGED: patterns/header-editorial.php now uses WordPress 7.0 native per-device block visibility (metadata.blockVisibility.viewport) to hide the status pill on mobile/tablet, replacing the hand-rolled @media rule in assets/styles/block-styles/editorial-header.css. Same visual result, no custom CSS.
* ADDED: Dimension size presets in theme.json (settings.dimensions.dimensionSizes: xs/sm/md/lg/xl mapped to 40/300/330/600/680px) for the WordPress 7.0 dimensions block support. Applied to the two wp:group blocks that previously used bare pixel min-heights: patterns/services-feature-cards.php (300px -> sm) and patterns/stats-showcase.php (40px -> xs). Cover-block min-heights are intentionally unchanged because core/cover does not participate in this preset system.
* TECHNICAL: Minimum WordPress version raised to 7.0. This release uses WordPress 7.0 features (dimension presets and block visibility) that are not available in earlier versions. Users on WordPress 6.x should upgrade before installing this version.
